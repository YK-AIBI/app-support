## 医療費スキャン（IryouhiScan）

レシート撮影で医療費控除の記録・集計・申請用Excel作成を支援するiPhoneアプリです。

**よくある質問**

**Q. レシートの画像やデータはどこに保存されますか？**
A. 端末内に保存されます。iCloud同期を有効にした場合のみ、ご本人のiCloudプライベートデータベースを通じて同じApple IDの他デバイスと同期されます。開発者のサーバーには送信されません。

**Q. 医療費控除用Excelの出力が有料になったのはなぜですか？**
A. レシートの記録・管理・家族での集計は無料でご利用いただけます。国税庁公式書式に対応した申請用Excelの出力のみ、年度ごとに買い切り（一度購入すればその年度は何度でも作り直せます）で提供しています。

**プライバシーポリシー**: https://claude.ai/code/artifact/c2038f60-cef4-4589-8449-ba8a522f0013

## 自動車リサイクルってなんやねん（CarRecycleNavi）

自動車リサイクル法（使用済自動車の再資源化等に関する法律）の条文144条を、やさしい言葉の要約つきで読めるiPhoneアプリです。

**よくある質問**

**Q. 通信しますか。入力した内容はどこかへ送られますか。**
A. 通信しません。条文も解説も挿絵もアプリに同梱しているため、機内モードでもすべての機能が使えます。外部へ送信する情報はありません。

**Q. ブックマークや履歴はどこに保存されますか。**
A. お使いの端末の中にだけ保存されます。アプリを削除すると消えます。履歴はアプリ内の「保存したもの」の画面からいつでも消せます。

**Q. 条文はいつ時点のものですか。**
A. e-Gov法令検索から取得した条文を収録しており、取得日をアプリ内に表示しています。法改正があった場合はアプリの更新で差し替えます。

**Q. アプリの解説をそのまま実務の判断に使えますか。**
A. 学習用であり、法的助言ではありません。やさしい解説と要約は、わかりやすさを優先した編集部による意訳です。正確な内容は、同じ画面から開ける条文の原文をご覧ください。実際の手続きや事業の判断は、所管官庁または専門家にご確認ください。

**プライバシーポリシー**: https://github.com/YK-AIBI/app-support/blob/main/carrecyclenavi-privacy.md
