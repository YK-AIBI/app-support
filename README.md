## よくある質問

**Q. レシートの画像やデータはどこに保存されますか？**
A. 端末内に保存されます。iCloud同期を有効にした場合のみ、ご本人のiCloudプライベートデータベースを通じて同じApple IDの他デバイスと同期されます。開発者のサーバーには送信されません。

**Q. 医療費控除用Excelの出力が有料になったのはなぜですか？**
A. レシートの記録・管理・家族での集計は無料でご利用いただけます。国税庁公式書式に対応した申請用Excelの出力のみ、年度ごとに買い切り（一度購入すればその年度は何度でも作り直せます）で提供しています。
